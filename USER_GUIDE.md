# User Guide: New Features

## 📊 Exporting Individual Threat Reports

### PDF Export
1. After checking an IP, URL, malware hash, or cyber threat indicator
2. Click the **PDF** button in the "Threat Intelligence Results" section
3. A formatted PDF report will be downloaded automatically
4. PDF includes a summary with risk level, score, and all intelligence sources

### Excel Export
1. After checking a threat indicator
2. Click the **Excel** button in the "Threat Intelligence Results" section
3. An Excel workbook will be downloaded with:
   - Summary sheet with check details
   - Results sheet with all threat source data

## 📁 Exporting Full Check History

### Navigate to History Tab
1. Click the **History** tab in the dashboard
2. All your previous checks are now organized by type:
   - IP Checks
   - URL Checks
   - Malware Analysis
   - Cyber Threats

### Export All History
1. In the History tab header, click **PDF** or **Excel** buttons
2. Exports all checks in all categories as a single document
3. PDF includes separate sections for each threat type
4. Excel includes separate sheets for each threat type

## 🎨 Color Scheme Guide

### Risk Levels (Now Consistent)
- **🔴 High Risk / Malicious**: Red (#EF4444)
- **🟠 Medium Risk / Suspicious**: Orange (#F59E0B)
- **🟢 Safe**: Green (#22C55E)

These colors are applied consistently across:
- History badges
- Risk score indicators
- Export documents
- Dashboard cards

### Theme Colors
- **Primary Blue-Gray**: #2D3E4E (Tab bar background, titles)
- **Light Cream**: #F2EBE5 (Tab bar text, light elements)
- **Teal Accent**: #8CBDB9 (Active tabs, accents, borders)
- **White**: #FFFFFF (Card backgrounds)
- **Text Gray**: #647295 (Body text)

## 💡 Tips & Tricks

✅ **Bulk Downloads**: Export your entire history at once to keep records
✅ **Categorized View**: Switch between threat types in the History tab for better organization
✅ **Color Coded**: Risk levels are color-coded for quick visual scanning
✅ **PDF Sharing**: Share PDF reports with team members easily
✅ **Excel Analysis**: Import Excel exports into spreadsheet tools for further analysis

## Troubleshooting

**Export button not working?**
- Ensure you have JavaScript enabled in your browser
- Try a different export format (PDF or Excel)
- Check your browser's download settings

**History not showing?**
- Check if cookies/localStorage is enabled
- Clear browser cache and refresh
- Re-run a check to see history update

**Colors not displaying correctly?**
- Try switching between light/dark mode
- Clear browser cache
- Ensure CSS is fully loaded
